# Busqueda - HackTheBox Writeup

[Busqueda](https://app.hackthebox.com/machines/busqueda) is an Easy Linux machine on HackTheBox. The site runs a Flask app wrapping the `Searchor` Python package, version 2.4.0, which passes user input straight into `eval()` — a command injection vulnerability that gives a foothold as `svc`. Credentials recovered from a leftover `.git` config lead to a local Gitea instance, and a `sudo`-runnable checkup script that invokes a helper via a relative path lets that reference be hijacked for full root.
